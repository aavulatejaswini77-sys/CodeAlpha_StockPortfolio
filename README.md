# Stock Portfolio Tracker Using Python

## Project Description
This is a simple Stock Portfolio Tracker developed using Python as part of the CodeAlpha Python Internship.

This program allows users to enter stock names and quantities. It calculates the total investment based on predefined stock prices and displays the portfolio details.

The portfolio information is also saved in a text file.

## Features
- Stores stock prices using a dictionary.
- Accepts stock names and quantities from users.
- Calculates individual stock investments.
- Calculates total investment.
- Displays portfolio details.
- Saves portfolio information in a text file.

## Technologies Used
- Python

## Key Concepts Used

- Input and Output
- Basic Arithmetic
- File Handling
- For Loop
- If-Else Statements

## How to Run
1. Download the `stock_portfolio.py` file.
2. Open it using Python.
3. Run the program.
4. Enter the number of stocks.
5. Enter stock names and quantities.
6. View the total investment.
7. Portfolio details will be saved in `portfolio.txt`.

## Output File
The program automatically creates `portfolio.txt` to store stock names, quantities, and total investment.
